# Ollama 사용 한도 (Aside / Chrome 확장 프로그램)

ollama.com 클라우드 계정의 **세션·주간 사용 한도**를 툴바에서 바로 확인하는 확장 프로그램입니다.
Aside(Chromium 기반)와 Google Chrome에서 그대로 쓸 수 있습니다.

## 무엇을 보여주나

| 항목 | 설명 |
| --- | --- |
| 툴바 뱃지 | 세션 사용률(%). 기본 설정은 세션 기준이며 주간 또는 둘 중 높은 값으로 바꿀 수 있음 |
| 세션 사용량 | 5시간마다 초기화되는 사용률 + 초기화 시각 + 남은 시간(1초마다 갱신) |
| 주간 사용량 | 7일마다 초기화되는 사용률 + 초기화 시각 + 남은 시간 |
| 모델별 요청 수 | 각 게이지 아래 범례에 모델 색상 + 모델명 + 요청 건수 (색상은 ollama.com 표시와 동일, 세션/주간 각각) |
| 사용 크레딧 잔액 | 추가 구매한 사용 크레딧 잔액 |
| 한도 알림 | 세션 사용률이 경고 기준(기본 90%)을 넘으면 OS 알림 |

뱃지 색상: 60% 미만 초록, 60~85% 주황, 85% 이상 빨강.
로그인이 안 되어 있으면 뱃지가 `OFF`, 읽기에 실패하면 `!`로 표시됩니다.

## 값을 읽는 방식

- 로그인된 **브라우저 세션 쿠키**로 `https://ollama.com/settings` HTML을 읽어 파싱합니다. **API 키가 필요 없습니다.**
  (`session usage 8.8% used`, `data-model`/`data-requests`, `#extra-usage-balance` 같은 안정적인 마크업만 사용)
- ollama.com이 공식 제공하는 `GET /api/usage`는 API 키(`Authorization: Bearer`)를 요구하므로 사용하지 않았습니다.
  나중에 API 키를 만들면 JSON 기반으로 바꾸는 편이 더 견고합니다.
- 로그인 만료, 페이지 개편, 네트워크 오류는 팝업에 그대로 표시되고 값은 지워지지 않습니다.

## 설치 (한 번만, 수동 3단계)

확장 프로그램은 보안상 자동 설치가 불가능해 아래 과정을 한 번 거쳐야 합니다.

1. `chrome://extensions` 열기 (Aside 주소창에 붙여넣기)
2. 오른쪽 위 **개발자 모드** 켜기
3. **압축해제된 확장 프로그램을 로드합니다** 클릭 → 이 폴더 선택

> 폴더 선택 창에서 `Cmd+Shift+G`를 누르고 이 경로를 붙여넣으면 빠릅니다:
> `/Users/kangbyungjun/projects/ollama-usage-extension`

설치 후 툴바에서 아이콘을 고정(pin)하면 뱃지가 항상 보입니다.
이 폴더를 옮기거나 지우면 확장이 깨지므로 위치를 고정해서 쓰세요.

## 설정

확장 아이콘 우클릭 → **옵션**(또는 팝업의 `설정` 버튼)

- 자동 갱신 주기: 기본 5분 (1~120분)
- 경고 알림 기준: 기본 90% (세션 기준)
- 표시 방식: 숫자 뱃지(기본) / 원형 게이지
- 뱃지·게이지 기준: 세션 / 주간 / 둘 중 높은 쪽
- 한도 알림 켜기·끄기

### 표시 방식: 숫자 뱃지 vs 원형 게이지

| 방식 | 보이는 모습 |
| --- | --- |
| 숫자 뱃지 (기본) | 아이콘 위에 사용률 숫자. 색은 60% 미만 초록 / 60~85% 주황 / 85% 이상 빨강 |
| 원형 게이지 | 아이콘을 감싸는 원형 게이지. 숫자는 숨기고, 12시 방향에서 시계방향으로 채워짐 |
| 원형 게이지 + 숫자 | 게이지와 숫자를 함께 표시(같은 슬롯에서 정보량 최대) |

- 원형 게이지는 `chrome.action.setIcon({ imageData })`로 **런타임에 그려서** 넣습니다(`background.js`의 `ringIconImageData`).
  OffscreenCanvas로 16px/32px 두 벌을 만들어 레티나 툴바에서도 선명합니다.
- 게이지 색은 숫자 뱃지와 같은 심각도 색을 쓰고, 바탕 트랙은 반투명 회색입니다.
- OffscreenCanvas를 쓸 수 없는 환경이면 자동으로 숫자 뱃지로 돌아갑니다.
- 16/32/48px 자산을 함께 만들어 툴바 슬롯이 큰 환경에서도 선명합니다.

### 툴바 아이콘 크기는 브라우저가 정합니다

툴바 슬롯 크기는 Aside/Chromium UI가 고정하므로 확장이 키울 수 없습니다. 대신 그림은 슬롯을 100% 채우도록 그립니다
(32px 캔버스에서 링 바깥지름 32px, 이전 97% → 100%). 더 크게 보이게 하려면 색 면적이 큰 방식을 고르는 수밖에 없습니다.

## 파일 구성

```
manifest.json      MV3 매니페스트 (권한: storage, alarms, notifications / host: ollama.com)
background.js      사용량 조회·파싱, 뱃지 갱신, 주기 실행, 알림
popup.html/.css/.js 팝업 UI
options.html/.js   설정 UI
icons/             아이콘 (16/32/48/128) = ollama.com 공식 파비콘
icons/original-gauge-backup/  처음 만든 게이지 아이콘 백업
tools/make-icons.mjs 게이지 아이콘 생성기 (외부 라이브러리 없이 PNG 직접 인코딩)
```

## 아이콘

아이콘은 ollama.com이 파비콘으로 쓰는 공식 PNG를 그대로 사용합니다(흰 라운드 사각형 + 검은 라마).

- `icon16/32/48.png` = `https://ollama.com/public/icon-16x16.png`, `icon-32x32.png`, `icon-48x48.png`
- `icon128.png` = `https://ollama.com/public/apple-touch-icon.png`(180px)를 128px로 축소
- 알림 아이콘도 `icon128.png`를 그대로 씁니다.

되돌리려면 `icons/original-gauge-backup/`의 파일을 `icons/`로 복사한 뒤 확장을 새로고침하면 됩니다.
어두운 툴바에서 흰 사각형 없이 흰색 라마만 쓰고 싶다면 `icon*.png`를 흰색 라마(투명 배경)로 다시 만들면 됩니다.

## 주의

- 개인용 비공식 도구입니다. ollama.com이 페이지 구조를 바꾸면 파서를 손봐야 합니다
  (`background.js`의 `parseUsage`). 실패하면 뱃지가 `!`로 바뀌고 팝업에 이유가 표시됩니다.
- 사용량 조회 외에는 아무 것도 하지 않습니다. 값을 전송하는 서버도 없습니다(로컬 저장만).

## 변경 이력

- **2026-09-21 (표시 개선) 원형 게이지 두께 최종 6px**
  - 두께를 3px → 6px → 9px로 실험한 뒤 **중간값 6px로 확정**(16px에서는 3px). 트랙 투명도도 0.35 → 0.55로 진하게.
  - 안쪽 아이콘 여백도 줄여(0.94 → 0.97). 32px 캔버스 기준 링 6px, 안쪽 아이콘 19.1px(60%), 링 바깥지름 31.7px(슬롯 99% 채움).
  - 실측(69% 링의 수평 방향 진한 주황 픽셀 수): 3px링 2px → 6px링 5~6px → 9px링 8px. 최종 6px에서 캔버스 채움은 32/32px.

- **2026-09-21 (설정) 숫자 뱃지 / 원형 게이지 선택**
  - 설정에 `표시 방식` 추가(기본: 숫자 뱃지). 원형 게이지를 고르면 아이콘을 감싸는 게이지를 OffscreenCanvas로 그려
    `setIcon(imageData)`로 넣고 숫자 뱃지는 숨긴다. 게이지 색은 뱃지와 같은 심각도 색.
  - 검증: 0/14/46/69/92%를 실제 코드로 렌더링해 링 픽셀을 샘플링(0% 빈 링, 14·46% 초록 #16a34a, 69% 주황 #f59e0b, 92% 빨강 #dc2626,
    각도도 12시 기준 시계방향 비율과 일치).
- **2026-09-21 (버그 수정) 주간 게이지가 실제 사용률보다 꽉 차 보이던 문제**
  - 증상: 주간 21.7%인데 색상 막대가 트랙 전체(100%)를 덮어 게이지가 거의 꽉 찬 것처럼 보임.
  - 원인: ollama.com이 주는 `data-usage-segment`의 `style="width: N%"`는 **트랙 전체가 아니라 "사용한 구간(fill) 대비" 비율**이다.
    수정 전 코드는 이 값을 트랙 전체 폭 기준으로 그려서, 막대가 사용 구간과 무관하게 늘어났다.
  - 수정: 모델별 색상 막대를 fill 안쪽 자식으로 옮기고(`popup.js`), fill에 `display:flex` + `overflow:hidden`을 걸어 넘친 부분을 잘라냄(`popup.css`).
    요청이 적어 비중이 0%로 내려온 모델은 ollama.com과 동일하게 최소 2px 슬라이버로 유지(`minWidth: 2px`).
  - 검증(같은 시점 실측): ollama.com 자체 렌더링은 트랙 504px / 사용 구간 109.4px(21.7%) / 막대 2+92.5+16.8,
    확장 팝업은 트랙 312px / 사용 구간 67.7px(21.7%) / 막대 2+57.3+10.4. glm-5.3 비중 84.6% vs 84.5%로 일치.
  - 이 수정은 HTML/CSS 변경이라 **확장 새로고침이 필요**하다(파일만 바꾸면 반영되지 않음).
- **2026-09-21 아이콘 교체**: 게이지 아이콘 → ollama.com 공식 파비콘(흰 라운드 사각형 + 검은 라마). 이전 아이콘은 `icons/original-gauge-backup/`.
- **2026-09-21 초판**: 사용량 조회·파싱(`background.js`), 팝업, 설정, 뱃지, 알림.
- **2026-09-21 (표시 개선) 세션 게이지도 모델별 색상으로 구분**
  - 증상: 주간 게이지는 모델별 색이 나뉘는데 세션 게이지는 항상 단색(심각도 색)으로만 보였다.
  - 원인: 색상 막대를 `models.length > 1`일 때만 그리도록 해서, 세션 구간처럼 모델이 하나뿐일 때는 색 구분이 빠졌다.
  - 수정: 모델이 1개여도 항상 모델 색으로 칠하고(ollama.com과 동일), 색이 어떤 모델인지 알 수 있게 각 게이지 아래에
    범례(색 스와치 + 모델명 + requests)를 붙였다. 기존 하단의 "이번 주 모델별 요청 수" 목록은 주간 게이지 범례로 통합.
  - 검증(2026-09-21 실측): 세션 14.2% 구간이 deepseek-v4.1-flash 색(#4f46e5)으로 채워지고, 주간은
    gemma4(2px 슬라이버)/glm-5.3/deepseek 3색으로 표시. 두 게이지 모두 색상 막대 합계가 사용 구간 안에 들어온다.
